# Data analysis project

Our project is titled **PWT Dataproject** and is about xxx.

The **results** of the project can be seen from running [dataproject.ipynb](dataproject.ipynb).

We apply the **following datasets**:

1. PWT 10.01 (*https://www.rug.nl/ggdc/productivity/pwt/?lang=en*)
2. IMF Financial Development Index database (*https://data.imf.org/?sk=f8032e80-b36c-43b1-ac26-493c5b1cd33b*)

**Dependencies:** Apart from a standard Anaconda Python 3 installation, the project requires the following installations:

``pip install matplotlib-venn``
``pip install linearmodels``
