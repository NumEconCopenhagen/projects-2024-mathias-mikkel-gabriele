# Model analysis project

Our project is titled **AS-AD model for an open economy with flexible inflation targetting**, and we analyze how different kinds of shocks impact the economy and how the central bank reacts in response.

The **results** of the project can be seen from running [AS-AD-model.ipynb], while the ASADmodel.py file contains a class with functions to solve and produce shocks to the model.

**Dependencies:** Apart from a standard Anaconda Python 3 installation, the project requires no further packages.
