This repository contains  
1. Inaugural project. Our solutions to the inaugural project. 
2. Data project. We fetch data from **PWT** and **IMF** on **countries**. 
3. Model project. We model a version of the AS-AD model for an open economy with flexible inflation targeting. We analyze the impact of different types of shocks, static, AR(1) and stochastic. 
4. Examproject. Answer to the 2024 summer exam.
